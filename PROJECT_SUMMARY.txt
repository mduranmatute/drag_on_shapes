================================================================================
KEY FEATURES IMPLEMENTED
================================================================================

1. PHYSICS MODEL
   - Incompressible Navier-Stokes equations in Stokes limit
   - Creeping flow regime (Re << 1)
   - Tunable Reynolds number parameter
   - Dynamic viscosity computed from Re = ρ*U*L/μ

2. GEOMETRY
   - Cubic domain with variable side length L
   - Sphere centered at origin with diameter = L/2 (radius = L/4)
   - No-slip boundary condition on sphere surface
   - Uniform inlet flow in x-direction

3. NUMERICAL METHODS
   - Centered grid discretization (Basilisk framework)
   - Adaptive mesh refinement (octree structure)
   - Wavelets-based refinement criterion
   - Implicit time integration for stability

4. FORCE CALCULATION
   - Drag force computation via stress tensor integration
   - Pressure drag and viscous drag components
   - Comparison with analytical Stokes theory
   - Drag coefficient normalized by inlet velocity

5. OUTPUT & VISUALIZATION
   - VTU format files for ParaView/VisIt visualization
   - Drag history saved to drag_history.txt
   - Real-time diagnostics to console/log files
   - Python post-processing with matplotlib

================================================================================
TUNABLE PARAMETERS
================================================================================

Physics:
  - REYNOLDS (default: 0.1)
  - INLET_VEL (default: 1.0)
  - DOMAIN_SIZE (default: 1.0)

Numerics:
  - LEVEL_MAX (default: 9) - Max mesh refinement level
  - LEVEL_MIN (default: 4) - Min mesh refinement level
  - MAX_TIME (default: 100.0) - Max simulation time
  - CFL_NUMBER (default: 0.5) - CFL stability criterion

Compile-time modification example:
  qcc -O2 -DREYNOLDS=0.01 -DLEVEL_MAX=8 stokes_sphere.c -o solver -lm

================================================================================
EXPECTED RESULTS
================================================================================

For Stokes flow (Re << 1), the total drag should approach:
  F_Stokes = 6π × μ × r × U₀

Example for Re = 0.1, L = 1.0, U₀ = 1.0:
  - μ = 10 (from Re = ρ*U*L/μ with ρ=1)
  - r = 0.25 (sphere radius)
  - F_theory = 6π × 10 × 0.25 × 1 = 47.12

Computed values should be within 5-10% of theory with adequate mesh refinement.
